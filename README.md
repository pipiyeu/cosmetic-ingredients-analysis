# Mandali - Cosmetic Ingredients Analysis

Mandali is an AI-powered web application for analyzing cosmetic ingredients and identifying potential cosmetic benefits and side effects using multi-label machine learning.

## Features

- Cosmetic ingredient analysis
- Multi-label prediction
- Benefit identification
- Side effect identification
- Machine learning-based analysis
- Responsive web interface

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
- Scikit-learn
- XGBoost
- scikit-multilearn

### Machine Learning
- TF-IDF
- Chi-Square Feature Selection
- Binary Relevance
- Multi-Label Classification
